AI-Powered Insider Threat Detection System

A hybrid behavioral analytics system combining Isolation Forest anomaly detection with keyword-based rule scanning to flag potential insider threats from logon, device, HTTP, file, and email activity.

Tech Stack

  • Flask, Flask-SQLAlchemy, Flask-Login
  • scikit-learn (Isolation Forest, StandardScaler)
  • SQLite
  • Trained on the CERT r4.2 Insider Threat Dataset (Carnegie Mellon University)

How Detection Works

  1. Keyword fast-path scans event content for suspicious terms
  2. Isolation Forest scores behavioral features for anomalies
  3. Contextual factors (after-hours, weekend, device events) adjust final risk severity
  4. Alerts are classified into CRITICAL / HIGH / MEDIUM / LOW
