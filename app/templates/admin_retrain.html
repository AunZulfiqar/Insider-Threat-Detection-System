What happens during retraining:
  1. Collects labeled alerts (TRUE/FALSE POSITIVE)
  2. Trains supervised classifier
  3. Updates Isolation Forest
  4. Creates whitelist patterns
  5. Suggests optimal thresholds
What Gets Retrained?
Supervised Classifier

Learns to distinguish between true threats and false positives using Random Forest algorithm.

  • Predicts if an alert is likely a false positive
  • Provides confidence scores
  • Improves with more labeled data
Isolation Forest

Updated to exclude false positive patterns from anomaly detection.

  • Retrained without false positive samples
  • More accurate anomaly detection
  • Reduces noise in future alerts
Whitelist

Common false positive patterns automatically filtered.

  • Extracts patterns from false positives
  • Automatically skips similar events
  • Saves analyst time
Thresholds

Analyzes feedback to suggest optimal risk thresholds.

  • Optimized based on actual data
  • Balances detection vs false positives
  • Can be applied in settings
How to Prepare Training Data
For True Threats:
  1. Go to Alerts page
  2. Click "View Details" on a confirmed threat
  3. Change status to CLOSED
  4. Add resolution notes explaining why it's a threat
  5. Click "Update Alert"
For False Positives:
  1. Go to Alerts page
  2. Click "View Details" on a benign alert
  3. Change status to FALSE POSITIVE
  4. Add notes explaining why it's safe
  5. Click "Update Alert"
Best Practices:
  • Label at least 10 alerts before first retraining
  • Try to balance true threats and false positives (50/50 is ideal)
  • Add detailed resolution notes for better learning
  • Retrain weekly or monthly as you label more alerts
  • Monitor false positive rate to measure improvement
